# Changelog

This Node.js package is a command-line wrapper for the `scattering.core` Java library. 

Because both the core library and this wrapper are maintained within the same repository and share a unified release cycle, all notable changes, updates, and release notes are documented centrally.

Please refer to the main project's Changelog on GitHub:
**[Scattering Core Main Changelog](https://github.com/light-scattering/scattering.core/blob/master/CHANGELOG.md)**
